# Регрессионный чек-лист перед релизом (CTO TZ §5)

Автоматическая часть: `npm test` — 20 вымышленных профилей (`tests/regression/profiles.ts`) прогоняются через фильтры программ, статусы соответствия, временной контекст, валидацию плана, проверку стипендий и арифметику квоты **без вызовов ИИ**. Эта таблица — ручная часть, где нужен живой ИИ или устройство.

Аккаунт для проверок: `qa.deadline.test@example.com` (пароль в `.env.qa.local`, лимит Free = 3 запроса/день; для длинных сценариев временно поставить `tier=pro` в таблице `profiles`).
