# База программ — как наполнять и проверять

Единица рекомендации University Advisor — **конкретная программа** (вуз + официальное название + уровень + язык + набор).
AI может рекомендовать только строки этой базы; всё остальное он обязан помечать как «не подтверждено».

## Файлы
- `programs-template.csv` — шаблон с одной строкой-примером.
- `programs-seed-2026-09-28.csv` — стартовый набор (9 программ: Италия/Германия, Economics & Finance, бакалавриат),
  собран и **проверен Claude по чек-листу ниже 28.09.2026** (каждая строка сверена с официальными страницами: название,
  язык, стоимость, правило 11 классов, тесты, английский, дедлайн). Статус `verified` — 8 строк; `needs_review` — Frankfurt
  School (не подтверждено признание 11-летнего аттестата). Уточнения по итогам проверки: Bayreuth P&E частично на немецком
  (B2) → язык `de`; Ca' Foscari — фикс €1 300/год для non-EU; Bologna — Узбекистан не в списке MUR «особо бедных» → ставка
  €1 000 + €157; Bocconi — IELTS 6.5 (не ниже 6.0 по секциям); Cattolica — IELTS 6.0; Luiss — B2 (IELTS 6.0).
  Данные на набор 2027 всё равно нужно перепроверять весной 2027, когда вузы опубликуют дедлайны и стоимость 2027/28.

## Как импортировать
Админка → **Программы (база)** → вставить CSV или выбрать файл → «Импортировать».
Повторный импорт той же программы (тот же вуз + программа + уровень + язык + год набора) **обновляет** строку, а не дублирует.
Нужна миграция `supabase/migrations/0024_programs.sql`.

## Обязательные колонки
`university_name, country, program_name, level (bachelor|master|phd|foundation), source_url` (официальная ссылка).

## Ключевые поля и допустимые значения
| Поле | Значения | Зачем |
|---|---|---|
| `language` | `en`, `it`, `de`, … | фильтр «язык обучения» |
| `intake_year` | 2027 | фильтр «набор»; дедлайн относится к этому году |
| `tuition_amount` + `tuition_currency` + `tuition_period` | число, `EUR`, `year|semester|total` | фильтр по бюджету и расчёт дефицита финансирования |
| `accepts_11_year_school` | `yes` / `no` / `conditional` / `unknown` | барьер 11-летней школы проверяется ДО рекомендации; `unknown` ≠ «подходит» |
| `required_exams` | через `;` или `\|`: `SAT`, `TOLC-E`, `Bocconi online test`… | статус «нужно выполнить условия» |
| `english_requirement` | текст с баллом: `IELTS 6.0 …` | сравнение с профилем |
| `application_deadline` + `deadline_status` | `YYYY-MM-DD`; `published` / `not_published` / `estimated` | «официальный дедлайн» vs «не опубликован» vs «неподтверждённый ориентир» |
| `verified_at`, `verified_by`, `status` | дата; кто; `verified` / `needs_review` / `draft` / `archived` | после проверки специалист ставит `verified` |

## Чек-лист проверки для специалиста
1. Открыть `source_url`, сверить название программы, язык, стоимость и год набора.
2. Проверить правило для 11-летней школы (Италия: 1 год университета или foundation; Германия: Studienkolleg **W-Kurs**, не T-Kurs).
3. Проставить минимальный балл английского и обязательные тесты.
4. Дедлайн: только для нужного набора; если не опубликован — оставить пустым и `not_published`.
5. Сменить `status` на `verified`, заполнить `verified_at` и `verified_by`, импортировать заново.
